# SurveyOps Lite: frontend

React 19 + TypeScript + Vite + Tailwind CSS. See the [project README](../README.md) for what the app does, how to run it, and the architecture.

```bash
npm install
npm run dev      # dev server; forwards /api to http://localhost:4001 (see vite.config.ts)
npm run build    # type-check and build to dist/
npm run lint     # oxlint
```
